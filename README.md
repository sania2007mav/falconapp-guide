## Разделы приложения

1. **Обзор** — KPI остатков, диаграммы, избранное, недавние, алерты низких остатков  
2. **Дашборды** — выручка, менеджеры, топы, ABC, дебиторка, склад  
3. **Номенклатура** — папки, поиск, штрихкод, цены, остатки  
4. **Заказы** — история заказов клиентов из 1С  
5. **Заказ покупателя** — корзина, партнёр, создание документа, печать
